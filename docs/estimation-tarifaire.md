## Ce qui justifie le haut de fourchette

Ce n'est **pas un site vitrine** — c'est une application métier complète :

- Authentification réelle (Supabase Auth, JWT)
- Dashboard multi-sections avec gestion de données complexes
- Module cotisations avec historique par membre/année
- Intégration paiement (FedaPay KYC)
- Deux modes thème (clair/sombre) + mode maintenance
- Contraintes accessibilité WCAG AA + performance mobile Afrique

## Remarques pour le contexte associatif

**Tarif solidaire :** beaucoup de freelances acceptent -30 à -50 % pour les associations loi 1901 ou équivalent, en échange d'une mention dans les crédits et d'une référence.

**Option régie vs forfait :**
- En **forfait** (prix fixe) : le prestataire prend le risque des dépassements — prix plus élevé.
- En **régie** (TJM × jours réels) : plus souple, mieux adapté à un projet qui évolue comme celui-ci.

**Valeur réelle livrée :** autour de **15 000–25 000 €** au prix marché français mid-level, si on facturait tout depuis le début. C'est un projet sérieux pour une structure associative.
